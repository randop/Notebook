# DNS hostnames

Private DNS provider hostnames

- **one.one.one.one**          → cloudflare (default, no filtering)
- **1dot1dot1dot1.cloudflare-dns.com** → cloudflare (alternative hostname)
- **dns.quad9.net**            → quad9 (malware blocking)
- **dns.google**               → google public dns
- **dns.adguard-dns.com**      → adguard dns (default)
- **family.adguard-dns.com**   → adguard family protection
- **dns.adguard.com**          → adguard (older/common alternative)
- **dns.mullvad.net**          → mullvad dns (default)
- **adblock.dns.mullvad.net**  → mullvad + adblocking
- **base.dns.mullvad.net**    → mullvad + adblock + malware
- **family.dns.mullvad.net**  → mullvad + family filter
- **p0.freedns.controld.com** → control d (default/unfiltered)
- **p1.freedns.controld.com** → control d + malware
- **p2.freedns.controld.com** → control d + ads + trackers + malware
- **family.freedns.controld.com** → control d family
- **security-filter-dns.cleanbrowsing.org** → cleanbrowsing security
- **adult-filter-dns.cleanbrowsing.org** → cleanbrowsing adult filter
- **family-filter-dns.cleanbrowsing.org** → cleanbrowsing family filter
- **dns.nextdns.io**           → nextdns (requires your personal id after / for custom config)
- **doh.dns.sb**              → dns.sb (privacy-focused)
- **dnsforge.de**             → dnsforge (german privacy-focused)
- **dot.nl.ahadns.net**       → ahadns netherlands (dot variant)
- **doh.nl.ahadns.net**       → ahadns netherlands (doh)
- **doh.ffmuc.net**           → ffmuc (munich privacy project)
- **dns.digitale-gesellschaft.ch** → digital society switzerland
- **odvr.nic.cz**             → cz.nic (czech republic)
- **dns.tiar.app**            → tiar (privacy-focused)
- **doh.li**                  → doh.li (minimal logging)
- **dns.sb**                  → dns.sb (alternative format)
- **cloudflare-dns.com**      → cloudflare (dot variant)
