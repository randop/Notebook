# Toll

The Skyway (including Stages 1, 2, and 3) is operated by San Miguel Corporation (SMC) and uses the **AutoSweep RFID** system as its primary electronic toll collection method. AutoSweep is specifically designed for SMC tollways, which include:

- Skyway
- South Luzon Expressway (SLEX)
- NAIA Expressway (NAIAX)
- STAR Tollway
- TPLEX
- MCX

If you have an active AutoSweep RFID sticker with sufficient balance, it will work seamlessly at Skyway toll plazas for cashless, contactless payments.

For context on broader use (as of late 2025 onward): The Philippines launched the **"One RFID, All Tollways"** program in October 2025. This allows interoperability between AutoSweep and Easytrip systems across major Luzon expressways. You can enroll (it's optional and free) via the AutoSweep or Easytrip websites/apps to link accounts and use one RFID/balance for all covered tollways (including NLEX, SCTEX, etc., which were previously Easytrip-only).

But for Skyway specifically, a standard AutoSweep RFID has always been (and still is) fully compatible and accepted—no extra steps needed unless you're trying to use an Easytrip sticker there (which requires enrollment in the unified program).
