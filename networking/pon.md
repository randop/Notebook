# PON

| Feature              | **EPON**                  | **GPON**                      | **XPON**                          |
|----------------------|---------------------------|-------------------------------|-----------------------------------|
| **Standard**         | IEEE 802.3ah             | ITU-T G.984                   | Hybrid (supports both)           |
| **Downstream**       | 1.25 Gbps                | **2.488 Gbps**                | 1.25G or 2.5G (depends on mode)  |
| **Upstream**         | 1.25 Gbps (symmetric)    | 1.244 Gbps                    | Matches the mode                 |
| **Frame Type**       | Ethernet frames          | GEM (ATM-like)                | Auto or selectable               |
| **Efficiency**       | Lower                    | Higher                        | Depends on mode                  |
| **ONU Compatibility**| EPON ONUs only           | GPON ONUs only                | **Both EPON + GPON ONUs**        |
| **Common in PH**     | Less common now          | Most popular                  | Very common (especially cheap Chinese devices) |
| **Best for**         | Older networks           | Modern FTTH, higher speed     | Flexibility / mixed ONUs         |
