# SHASUM

| File | Format | Generated by |
|---|---|---|
| `SHA512SUMS.asc` | ASCII-armored (base64, human-readable text) | `gpg --armor --detach-sign SHA512SUMS` |
| `SHA512SUMS.sig` | Binary (raw, not human-readable) | `gpg --detach-sign SHA512SUMS` |

The cryptographic content is identical; `.asc` is simply the same signature wrapped in base64 with `-----BEGIN PGP SIGNATURE-----` headers. Projects typically ship one or the other (Debian uses `.sig`, some others use `.asc`).

**Verification** works the same for either:

```bash
gpg --verify SHA512SUMS.asc SHA512SUMS
# or
gpg --verify SHA512SUMS.sig SHA512SUMS
```

If you only pass the signature file, `gpg` automatically looks for the data file by stripping the extension (`SHA512SUMS`), so `gpg --verify SHA512SUMS.asc` alone also works.

After a successful signature check, verify the actual ISO:

```bash
sha512sum --check --ignore-missing SHA512SUMS
```
